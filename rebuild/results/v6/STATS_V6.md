## 2. Disattenuated agreement

Values above 1 are not clipped. ## 3. Hierarchical bootstrap vs method-only intervals

Hierarchical: methods resampled within each group of the set and units resampled within each dataset independently, B = 1000, seed 6060. Units-only: units resampled, all methods kept. v5 method-only: interval as stored in stats_v5.json (source key in the JSON). Percentile intervals. Resampling units adds noise to every per-method mean, which attenuates agreement in each draw, so units-only and hierarchical intervals for agreement-type quantities sit partly below the point estimate (attenuation bias); this makes them conservative for 'greater than 0' claims.

Max abs per-pair difference, stratified vs size-weighted: dice|U+F 0.030, nsd|U+F 0.027, dice|U+K 0.024, nsd|U+K 0.019, dice|U+M 0.032, nsd|U+M 0.044. Pearson on percentiles vs exact identity: max 4.4e-16.

Why: within-group percentiles (rank - 0.5)/n_g have mean exactly 0.5 in every group, so there is no between-group covariance. The pooled covariance and variances are therefore sums of the within-group ones weighted by n_g, and the Pearson correlation of the pooled percentiles is sum_g n_g v_g r_g / sum_g n_g v_g, with r_g the within-group Spearman and v_g = (1 - 1/n_g^2)/12 without ties. That is a size-weighted average with weights n_g - 1/n_g, practically n_g. Spearman on the pooled percentiles re-ranks values that are already near-uniform grids, so it is close to the Pearson value. Hence stratified agreement adds no information beyond the within-group agreements: it reports their weighted mean.
